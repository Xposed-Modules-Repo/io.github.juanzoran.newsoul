## 适配环境

- Soul：4.88.0、6.37.0、6.38.0、6.39.0
- 签到与免费抽奖功能已在 Soul 6.37.0、6.38.0 环境验证
- LSPosed：API 102

## 安装

安装统一版，在 LSPosed 中启用模块并勾选 Soul 作用域，重启 Soul。
原公开版覆盖升级；原内部版用户先停用旧内部模块，再启用统一版。
保留 Soul 数据；统一版保留公开版设置，首次使用补入旧内部版尚未设置的项目与 AI 密钥。
后续可在 LSPosed 仓库检测更新
