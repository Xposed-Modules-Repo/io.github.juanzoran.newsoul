# NewSoul

Soul 插件，提供聊天工具、帖子筛选、信息伪装与广告控制

## 适配环境

- Soul：4.88.0、6.37.0、6.38.0（6.37.0 未实测）
- LSPosed：API 102

## 安装

安装公开版，在 LSPosed 中启用模块并勾选 Soul 作用域，重启 Soul
本仓库包名为 `io.github.juanzoran.newsoul`，旧包名无法覆盖升级
保留 Soul 应用及数据可沿用原插件配置
后续可在 LSPosed 仓库检测更新
